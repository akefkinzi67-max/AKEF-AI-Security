Install NAVIQRA

iPhone and iPad

Open the station’s approved HTTPS address in Safari. In the Share menu, choose Add to Home Screen. Open the new NAVIQRA icon to sign in.

Android phones and tablets

Open the station’s approved HTTPS address in Chrome. In Chrome’s menu, choose Install app or Add to Home screen when offered.

Windows

Use the NAVIQRA Windows setup launcher to start the local station. In Chrome or Edge, use the browser’s install command when offered.

Connection required

Sign-in, cameras, recordings, reports and station changes require the authorized station network and an active server. The offline page holds no station data.
